Master Resource List — 100% Free

Every resource here is free. No trials, no paywalls, no "free tier that expires." Where a paid upgrade exists, it's marked — but nothing in this program requires it.

Note on paid platforms: TryHackMe and HackTheBox Academy are excellent and worth the ~$14-20/month if anyone in the group can afford it later. But they are not needed for the 13 weeks. Every week has a working free path.

By week

Week 1 — Terminal & lab setup

  • Linux Journey — linuxjourney.com — free, gentle, well-structured intro
  • The Linux Command Line (William Shotts) — linuxcommand.org/tlcl.php — free full PDF, the standard reference
  • OverTheWire Bandit — overthewire.org/wargames/bandit — the best CLI trainer for absolute beginners
  • VirtualBox manual ch.1 — virtualbox.org/manual/ch01.html
  • Kali docs — kali.org/docs

Week 2 — Linux permissions & users

  • Linux Journey: Users, Permissions, Special Permissions — linuxjourney.com
  • GTFOBins — gtfobins.github.io — for understanding SUID abuse conceptually
  • Ubuntu RootSudo docs — help.ubuntu.com/community/RootSudo

Week 3 — Services, logs, Bash

  • Ryan's Bash Scripting Tutorial — ryanstutorials.net/bash-scripting-tutorial
  • systemd manual — freedesktop.org/software/systemd/man/systemctl.html
  • ExplainShell — explainshell.com — paste a command, get each part explained. Superb for pipelines.
  • ShellCheck — shellcheck.net — paste your script, get it critiqued. Use it on every script.

Week 4 — Networking I

  • Professor Messer Network+ — youtube.com/@professormesser — free full Network+ course
  • Practical Networking — practicalnetworking.net — exceptional on subnetting
  • Subnetting Practice — subnettingpractice.com — drill until it's automatic
  • AR Arabic supplement: IT Dose / عماد نشأت — strong visuals for networking fundamentals

Week 5 — TCP/UDP, DNS, DHCP, Wireshark

  • Wireshark docs — wireshark.org/docs
  • Wireshark Sample Captures — wiki.wireshark.org/SampleCaptures — real pcaps to analyze
  • Chris Greer (YouTube) — Wireshark tutorials, practical and clear
  • Malware-Traffic-Analysis.net — free pcaps of real malicious traffic

Week 6 — TLS, firewalls, Nmap

  • Nmap docs — nmap.org/book — the free official book
  • Nmap NSE scripts — nmap.org/nsedoc
  • Practical TLS (free course) — search "Practical TLS free" on YouTube

Week 7 — HTTP, cookies, sessions

  • MDN Web Docs — developer.mozilla.org — the authoritative reference
  • HTTP Cats — http.cat — status codes, memorably
  • Burp Suite Community — portswigger.net/burp/communitydownload — free version is fully sufficient

Week 8 — Web architecture, OWASP Top 10

  • PortSwigger Web Security Academy — portswigger.net/web-security — start here, spend the most time here
  • OWASP Top 10 — owasp.org/Top10
  • OWASP Juice Shop — owasp.org/www-project-juice-shop — modern, deliberately vulnerable app
  • DVWA — dvwa.co.uk — classic vulnerable app, easier than Juice Shop
  • AR Arabic supplement: إبراهيم حجازي Ibrahim Hegazy — web app vulnerabilities, excellent for Arabic speakers

Week 9 — Security core

  • Professor Messer Security+ — youtube.com/@professormesser — free full course
  • NIST CSF — nist.gov/cyberframework
  • MITRE ATT&CK — attack.mitre.org
  • OWASP Threat Modeling — owasp.org/www-community/Threat_Modeling

Week 10 — Cryptography

  • Crypto101 — crypto101.io — free book, the best beginner crypto text
  • Practical Cryptography for Developers — cryptobook.nakov.com — free, hands-on
  • PicoCTF crypto challenges — excellent progressive practice
  • Cryptohack — cryptohack.org — free, structured, challenging

Week 11 — Defensive

  • Wazuh — wazuh.com — fully open-source SIEM, installs on one VM
  • Security Onion — securityonion.net — free, heavier
  • Sigma — github.com/SigmaHQ/sigma — detection rules
  • NIST SP 800-61 — the incident handling guide, free PDF
  • LetsDefend — letsdefend.io — free tier, SOC analyst training
  • Blue Team Labs Online — blueteamlabs.online — free challenges
  • CIS Benchmarks — cisecurity.org/cis-benchmarks — free PDFs after registration
  • The DFIR Report — thedfirreport.com — real intrusion case studies

Week 12 — Offensive

  • PTES — pentest-standard.org
  • OWASP WSTG — owasp.org/www-project-web-security-testing-guide
  • Metasploitable2 — downloadable vulnerable VM
  • CVSS — first.org/cvss
  • HackTricks — book.hacktricks.xyz — free, comprehensive offensive reference
  • PayloadsAllTheThings — github.com/swisskyrepo/PayloadsAllTheThings
  • AR Arabic supplement: ناكراه Nakerah Network — OSCP content, buffer overflow

Week 13 — Capstone

  • Everything above, combined.
  • TCM Security (YouTube) — youtube.com/@TCMSecurityAcademy — free full practical ethical hacking course
